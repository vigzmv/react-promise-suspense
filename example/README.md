# react-promise-suspense example

A minimal [Vite](https://vitejs.dev) + React 18 app demonstrating `usePromise`
with `<Suspense>` and an error boundary. It consumes the package from the parent
directory via `"react-promise-suspense": "file:.."`, so the package must be
built first.

```bash
# From the repository root: installs dependencies and builds the package.
npm install

cd example
npm install
npm run dev
```

Then open the printed local URL.
